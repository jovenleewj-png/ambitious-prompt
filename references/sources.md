# Sources and adaptation

Checked 27 October 2026.

- Felix Rieseberg, [How to be more ambitious: A tutorial for humans with models](https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/), 13 October 2026. Source of the four ambition dimensions and the emphasis on expert instruments, raw inputs, assumption testing, outside validation, and useful cross-disciplinary methods. This skill selects dimensions according to the request and preserves the requested deliverable.
- Multica AI / originally forrestchang, [Karpathy-Inspired Claude Code Guidelines](https://github.com/multica-ai/andrej-karpathy-skills/blob/main/README.md). This repository organizes observations attributed to Andrej Karpathy into four behavioral principles. The four-point organization is a community synthesis, not claimed here as an official Karpathy framework. The repository links to [Karpathy's original post](https://x.com/karpathy/status/2015883857489522876); the original post was not independently retrieved during creation.

The domain-research protocol, cross-industry translation, model-capability fallbacks, proportionality rules, and prompt-approval-execution workflow are this skill's implementation choices. The approval gate follows the user's explicit preference. Source authors do not endorse this adaptation.
